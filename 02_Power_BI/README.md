# Data Professional Survey Analysis — Power BI

## Overview

This project presents an interactive Power BI dashboard built using data from a survey of data professionals.

The dashboard explores different aspects of the respondents' professional background, including job roles, salaries, programming language preferences, industries, geographic distribution, and job satisfaction.

The goal of the project was to transform raw survey data into an interactive dashboard that allows users to explore patterns and compare different aspects of the data profession.

## Dataset

The dataset contains 630 survey responses from data professionals.

The survey includes information about:

- Current job role
- Annual salary
- Industry
- Favorite programming language
- Country of residence
- Career transition into data
- Job satisfaction
- Work-life balance
- Satisfaction with management
- Satisfaction with career growth
- Satisfaction with learning opportunities
- Age and other respondent characteristics

## Dashboard

The Power BI dashboard provides an overview of the data professional landscape and allows users to explore the survey results interactively.

### Key areas of analysis

- Average salary by job title
- Programming language preferences
- Distribution of respondents by country
- Number of survey respondents
- Average respondent age
- Job satisfaction indicators
- Work-life balance satisfaction
- Satisfaction with learning new things
- Salary distribution by gender
- Industry filtering

## Key Analytical Questions

The dashboard was designed to answer questions such as:

- Which data roles have the highest average salaries?
- Which programming languages are most popular among data professionals?
- How are data professionals distributed across countries?
- Which industries employ the surveyed professionals?
- How satisfied are respondents with their work-life balance?
- How satisfied are respondents with opportunities to learn new things?
- How does average salary differ across genders?
- How does the composition of the data profession vary across different industries?
