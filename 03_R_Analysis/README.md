# Parks and Recreation Budget Analysis — R

## Overview

This project focuses on analyzing and visualizing budget data for the Parks and Recreation department using R.

The analysis explores how the budget is distributed across departments and how spending changes over time.

The goal of the project was to practice data manipulation and data visualization in R and transform raw budget data into clear and informative visualizations.

## Dataset

The dataset contains budget information for different departments and years.

Key variables used in the analysis include:

* Department
* Year
* Budget

The budget values are represented in thousands.

## Visualizations

The project includes three main visualizations:

### Total Budget by Department

Shows the total budget allocated to each department across the available years.

### Annual Budget for All Departments

Shows how the total annual budget changes over time.

### Annual Budget per Department

Compares annual budget trends across different departments and shows how their budgets change over time.

## Key Analytical Questions

The analysis was designed to answer questions such as:

* Which departments have the highest total budgets?
* How does the overall annual budget change over time?
* How does the budget vary between departments from year to year?
* Which departments show the largest changes in budget over time?

## Project Workflow

1. Imported the budget data from a CSV file.
2. Loaded and prepared the data using `dplyr`.
3. Aggregated budget values by department and year.
4. Created visualizations using `ggplot2`.
5. Built an R Markdown Flexdashboard to present the analysis.
6. Used charts to explore budget distribution and trends over time.
